# Debug.EXE
DEBUG.EXE Videojuego educativo creado para el curso de METCAMP, Mujeres en Tecnología 2026  Somos Sofia Digiano, Lucía Nazarena Marchetti y Selene Anahi Posadas y realizamos este juego eligiendo la temática educativa de Front End. La idea fue hacer un juego donde cualquiera que lo juegue aprenda cosas nuevas, y sobre todo que se diviertan haciendolo. Sobre el juego:  ¡Algo salió mal! Glitch ha provocado un desastre y ahora tendrás que poner a prueba tus conocimientos de desarrollo web para solucionar los problemas que dejó a su paso. A través de distintos desafíos, vas a explorar los fundamentos de HTML, CSS y JavaScript, resolver problemas y demostrar que tenés lo necesario para restaurar el sistema. Pero cuidado: Glitch no te lo va a poner fácil. Tenés tres vidas para superar los obstáculos y llegar al enfrentamiento final.  ¿Estás listo para aceptar el desafío y derrotar a Glitch?
